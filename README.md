# LagoonCreekTsunami

## Test problem for upcoming CRESCENT workshop.

For more information or to register, please see:
https://cascadiaquakes.org/science/tsunami-sources-for-hazard-assessment/

## Contents

This repository contains:

- Some markdown files, Jupyter notebooks, and plots/animations of sample results
  that are rendered using Jupyter Book and can be viewed at:
    https://depts.washington.edu/ptha/CopesHubTsunamis/LagoonCreek/

- Sample GeoClaw code used to run the simulations that generated the
  sample results.
