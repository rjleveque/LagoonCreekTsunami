Load Sample Source¶

Illustrate how to load a netCDF file for one source and plot it.

Also write it out as a GeoClaw dtopo file with ASCII raster format, as described in the GeoClaw Documentation, and make some plots using GeoClaw tools.

Adapt this code to write it out to whatever format you need.

Open with rasterio:¶

In [6]:
import rasterio
with rasterio.open(path) as src:
    print(f"Coordinate Reference System (CRS): {src.crs}")
    print(f"Bounds: {src.bounds}")
    print(f"Number of bands: {src.count}")
    print(f"Width/Height: {src.width}x{src.height}")
    
    meta = src.meta
    print('\nsrc.meta = \n')
    for k in meta.keys():
        print(f'{k:<30}{meta[k]}')
    
    tags = src.tags()
    print('\nsrc.tags = \n')
    for k in tags.keys():
        print(f'{k:<30}:  {tags[k]}')
